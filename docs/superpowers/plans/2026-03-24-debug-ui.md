# Debug UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a lightweight browser debug dashboard to the FastAPI project so users can upload images and inspect visualization and scoring outputs without manual API calls.

**Architecture:** The existing FastAPI backend remains the single analysis engine. A new server-rendered HTML page at `/` loads static CSS/JS assets, previews a selected image, posts base64 payloads to `/analyze`, and renders the returned debug data into panels and cards.

**Tech Stack:** FastAPI, Jinja2 templates, vanilla JavaScript, CSS, pytest
